# 基础镜像：pytorch/pytorch:2.13.0-cuda13.2-cudnn9-runtime（实测于 2026-11）
#   python 3.12.3 / torch 2.13.0+cu132 / CUDA 13.2 / cuDNN 9.20 / Ubuntu 24.04
#   torch.cuda.get_arch_list() = ['sm_75', 'sm_80', 'sm_86', 'sm_90', 'sm_100', 'sm_120']
#
# 为什么 10 系不在这里：CUDA 13.x release notes 明确「Dropped support for pre-Turing
# architectures (Maxwell, Volta, and Pascal)」，arch list 里没有 sm_60/61/70。
# 10 系 / V100 一律走 requirements-pascal.txt（py3.10 + torch 2.3.1 + CUDA 12.1）。
#
# ⚠️ arch list 里没有 sm_89（40 系）：Ada 卡依赖 sm_86 cubin 的 minor 版本兼容运行，
#    这是 CUDA 的既定行为（同一 major 内高 minor 可执行低 minor 的 cubin）。代价是
#    40 系在本栈上**拿不到 fp8**（fp8 需要原生 sm_89 kernel）。要 fp8 需换 cu128 变体。
#
# 依赖锁版纪律（与 pascal 版一致）：钉死具体版本，不写宽范围——差异只允许在
# 「一次有记录的升级」里发生，避免 diffusers/transformers 代次漂移把运行时冲掉。
